#  (HW1)

В этой папке находится исходный код предыдущего ДЗ — сервиса обнаружения
мошеннических транзакций. Файлы скопированы из локального проекта
`hw1_gubich_mlops`. Источник: https://github.com/SASHASTATION/hw1_gubich_mlops.

Этот код используется как основа для HW3:

- `interface/` — интерфейс Streamlit для отправки транзакций и просмотра результатов.
- `scoring_service/` — исходный сервис скоринга, обработка признаков,
  базовая модель и зависимости.
- `results_writer/` — исходный сервис записи результатов в PostgreSQL.
- `smoke_test/` — проверка прохождения транзакции через систему.
- `db/init.sql` — создание исходной таблицы результатов.

Изменения текущего ДЗ находятся в корне проекта: `scoring_service/`,
`results_writer/`, `pipeline/`, `dags/` и `db/migrations/`.
При сборке сервисов Docker сначала копирует файлы HW1, затем накладывает
обновлённые файлы HW3. Airflow использует обработку признаков и базовую модель
из `hw1/scoring_service/` напрямую.

Запускайте весь проект из родительской папки `hw3_gubich`:

```bash
docker compose up --build -d
docker compose ps
```

Конфигурация запуска находится в корневом `docker-compose.yml`.
