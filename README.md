# ДЗ 3 — переобучение модели с помощью Airflow

Продолжение [первого ДЗ](https://github.com/SASHASTATION/hw1_gubich_mlops) по обнаружению мошеннических транзакций. Система принимает транзакции через Kafka, оценивает риск мошенничества и сохраняет результат в PostgreSQL. В этом ДЗ добавлены автоматическое переобучение модели и проверка качества данных.

## Что добавлено

В Airflow работают три процесса (DAG):

| DAG | Что делает | Как часто |
|---|---|---|
| `supply_labeled_month` | Добавляет до 1 000 размеченных транзакций за следующий месяц; хранит историю за 36 месяцев | Каждые 10 минут |
| `retrain_fraud_model` | Обучает модель и сравнивает её с действующей | Каждые 5 минут |
| `check_data_quality` | Проверяет данные и создаёт HTML-отчёт | Каждые 10 минут |

Для обучения берутся три последовательных месяца: первые два — для обучения, последний — для проверки. Новая и действующая модели сравниваются на одном проверочном месяце по метрике Average Precision (AP). Новая модель публикуется, если её результат не хуже. При первой публикации сравнение с действующей моделью пропускается.

Сервис скоринга подхватывает опубликованную модель без перезапуска. Версия модели записывается вместе с результатом каждой транзакции. Повторные попытки задач не создают дубликаты данных и не переключают месяц повторно.

Проверка качества включает девять правил: наличие данных, допустимая метка мошенничества, время транзакции, исходные данные, обязательные признаки, неотрицательная сумма, отсутствие дубликатов, соответствие месяца и наличие координат. Если проверка не пройдена, отчёт сохраняется, а задача завершается с ошибкой.

## Запуск

Нужны запущенный Docker Desktop и Docker Compose v2. Рекомендуется выделить Docker 6–8 ГБ памяти. Все команды выполняются из корня проекта:

```bash
docker compose up --build -d
docker compose ps
```

При первом запуске создаются базы и 6 000 синтетических транзакций за три месяца. Эти данные нужны для демонстрации работы системы; оценивать по ним качество обнаружения реального мошенничества нельзя. Датасет и ключи API скачивать не нужно.

| Сервис | Адрес | Доступ |
|---|---|---|
| Airflow | http://localhost:8081 | `admin` / `admin` |
| Интерфейс Streamlit | http://localhost:8501 | Без авторизации |
| Kafka UI | http://localhost:8080 | Топики `transactions` и `scores` |
| PostgreSQL | `localhost:5433` | База `fraud_db`, пользователь `fraud_user`, пароль `fraud_password` |
